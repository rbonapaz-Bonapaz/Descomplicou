Como usar

  1. Arraste os equipamentos pelo cabeçalho.
  2. Se mover algo por engano, use Desfazer ou Ctrl+Z.
  3. Quando terminar de posicionar tudo do seu jeito, clique em Salvar padrão. Depois, Padrão restaura exatamente essas posições.
  4. Organizar continua fazendo uma organização automática; ela também pode ser desfeita.
  5. PDF organizado prepara uma disposição limpa apenas para exportar e depois devolve os equipamentos às posições anteriores.
  6. Relatório completo cria uma lista com todos os dados de cada equipamento e as conexões cadastradas.
  7. Clique no lápis para editar os dados técnicos do equipamento.
  8. No celular, use Inventário para abrir uma lista e lançar os dados com campos maiores.
  9. Clique em Conexão para ligar dois equipamentos. Wi‑Fi aparece pontilhado; cabo, contínuo. Para editar ou excluir, clique na linha ou use Conexões no topo.
  10. Os campos são salvos enquanto você digita, mesmo antes de clicar no botão Salvar.
  11. Use Salvar HTML para baixar uma cópia sem senhas, com equipamentos, conexões e posições.
  12. Use Backup para criar também uma cópia dos dados em formato JSON.

Privacidade: a senha de cada equipamento fica somente neste navegador e não é enviada ao Firestore, HTML, backup ou relatório.
